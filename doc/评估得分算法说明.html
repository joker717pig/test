代码位置（ESP32 端）：main/therapy/therapy_eval.c / .h（评估状态机 + 指标计算 + 评分）、main/dsp/emg_dsp.c / emg_force.c（信号处理与力度包络）、main/ui_page_cn/PelFlo_AssPage/（评估页 UI 与报告页）

临床依据来源：EDA_EMG/doc/治疗处方/利玮生物刺激反馈仪处方2026052501.md

0. 一句话总结

按 Glazer 4 阶段方案（前静息 → 快速收缩 → 持续收缩 → 后静息）采集盆底肌电的 力度包络（µV），以前静息均值作为个人基线做相对标定，算出 6 个分项得分 （各 0~100），再加权求和得到总分（0~100）。

1. 硬件与信号链路

项值
硬件ESP32-S3 主板 + ADS1292 生物电前端（24bit ADC）
采样率500 SPS（本次评估固定）
电极单通道 CH1（盆底肌）

信号处理链（逐样本递推，无 FFT）：

raw16 ─► 高通 25Hz ─► 陷波 50Hz(Q30) ─► 低通 150Hz ─► 整流 + EMA(4Hz) ─► 力度包络
  • 力度包络 = 评估用的"肌电幅度"信号，单位换算 1 LSB ≈ 6.15 µV（VREF=2.42V、增益 12）。
  • 评估引擎每 50ms 采样一次包络（即 20 样本/秒），既保证上升/恢复时间的分辨率，又降低计算量。

2. 评估流程（4 阶段，总时长 272s ≈ 4:32）

#阶段动作序列时长阶段内指标

每个动作步骤都有对应语音提示（"放松"/"用力"/"保持"）和屏幕三角峰/基线示意图引导。

3. 数据采集与指标

3.1 相对标定（关键设计）

  • 基线 baseline = 前静息期包络均值（µV）。
  • 力量/耐力都用 "相对基线的倍数" 表示，不依赖绝对 µV，以消除个体差异与电极位置差异。

3.2 各阶段算出的原始指标

阶段指标含义 / 计算
① 前静息rest1_avg包络均值 (µV)
① 前静息rest1_var变异性 CV% = std / mean × 100
② 快速收缩fast_max5 次用力峰值中的最大者 (µV)
② 快速收缩fast_max_ratio= fast_max / baseline（倍数）
② 快速收缩fast_rise平均上升时间 (s)：包络首超阈值 → 峰值
② 快速收缩fast_recover平均恢复时间 (s)：峰值 → 回落阈值
③ 持续收缩sust_avg保持段包络均值 (µV)
③ 持续收缩sust_ratio= sust_avg / baseline（倍数）
③ 持续收缩sust_var保持段变异性 CV%
④ 后静息rest2_avg / rest2_var同前静息

上升/恢复时间的检测阈值：阈值 = max(2 × baseline, 10 µV)。 每次用力段内做状态机：未触发 → 首超阈值(记上升起点) → 到峰值 → 回落阈值(记恢复)。

变异性 CV% 计算：CV% = sqrt(E[x²] - E[x]²) / E[x] × 100； 若均值 < 0.5 µV，直接记 0（视为"无有效信号，按完美稳定处理"）。

4. 评分算法

4.1 两个"是否真的做了"的门槛

  • has_force：快速收缩峰值 fast_max_ratio ≥ 2.0（即峰值 ≥ 2 倍基线）才算"真的用力"。
  • has_sust：持续收缩保持均值 sust_ratio ≥ 1.5 才算"真的保持"。

目的：未真正收缩/保持时，力量、速度、耐力、保持稳定直接记 0 分， 避免"全程静止却因 0s 上升时间 / 低 CV 拿高分"。

4.2 六个分项（各 0~100）

分项权重公式满分条件零分条件
力量25%has_force ? clamp01(fast_max_ratio / 10) × 100 : 0峰值 ≥ 10×基线峰值 ≤ 基线（或未收缩）
耐力25%has_sust ? clamp01(sust_ratio / 5) × 100 : 0保持均值 ≥ 5×基线保持均值 ≤ 基线（或未保持）
上升速度10%has_force ? lin(fast_rise, 0.5s, 2s) : 0≤ 0.5s≥ 2s
恢复速度10%has_force ? lin(fast_recover, 1s, 3s) : 0≤ 1s≥ 3s
静息稳定15%lin((rest1_var + rest2_var)/2, 10%, 30%)平均 CV% ≤ 10%≥ 30%
保持稳定15%has_sust ? lin(sust_var, 10%, 30%) : 0CV% ≤ 10%≥ 30%

其中：

  • clamp01(x)：把 x 截断到 [0, 1]。
  • lin(v, full, zero) = clamp01((zero − v) / (zero − full)) × 100：v ≤ full 得 100 分，v ≥ zero 得 0 分，中间线性。

4.3 总分

总分 = 力量×0.25 + 耐力×0.25 + 上升×0.10 + 恢复×0.10 + 静息稳定×0.15 + 保持稳定×0.15

（权重合计 1.00，总分 0~100）

7. 已知问题 / 待改进点（请重点评审）

  1. 所有阈值都是"拍脑袋"初值，没有临床依据：10×/5×/2×/1.5×/0.5s/2s/1s/3s/10%/30% 都待专家确认或按人群数据标定。
  2. 基线依赖前静息：若患者前静息没放松，基线偏高，所有"倍数"被系统性压低。
  3. 静息稳定不设收缩门槛（有意保留）：因此"全程静止"的人静息稳定仍能得高分（≈96），这部分是否合理需确认。
  4. 上升/恢复检测阈值 2×基线（≥10µV）：信号弱（基线极低）的人可能始终不触发，导致 fast_rise/recover = 0，目前靠 has_force 门控挡成 0 分，但语义上"测不到"和"真的很快"没区分。
  5. CV% 对低均值不稳定：均值 < 0.5µV 直接记 0（当"完美稳定"），低信号时会虚高。
  6. 无信号质量检测：没有电极脱落 / 接触不良 / 伪影检测，坏信号可能被当有效指标。
  7. 持续收缩期简化：8s 的"用力保持"被当成单段统计均值/变异，内部的"用力1s+保持6s+放松1s"没有细分，也未评估"保持过程中是否掉力"。
  8. 后静息没有显式"回到基线"检查：只统计均值/变异，没评估"用力后是否充分恢复"。
  9. 总分是各分项独立加权，未考虑指标间相关性（如力量强的人恢复通常也快）。
  10. 时间分辨率 50ms：对 ≤0.5s 的上升满分线够用，但若要更精细的爆发力指标（如 peak-to-peak 斜率），可能不够。
  11. 采样点按"阶段已过 tick"对齐，未做段内时间归一（每段时长固定，暂无影响）。

供评审后回填：请给出 ① 各阈值/权重的临床建议值；② 是否需要新增指标（如快速收缩的"收缩次数/疲劳度/后静息是否回到基线"）；③ 评分曲线（线性/分段）是否合理。
