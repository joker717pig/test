## ✅ 目检反馈修复（第二次，2026-08-12，烧录通过 0x167570 / 65% free）

> 用户目检 4 条反馈，全部处理；monitor 抓到亮度页 ESC 崩溃 backtrace（Guru Meditation LoadProhibited @ lv_event_send）。

1. **音量/亮度右端数字实时显示**：`Set_Widget_t` 加 `Label_VolValue/Label_BriValue`，Page1/Page2 绑定右端"5"标签，`VALUE_CHANGED` 里 `lv_label_set_text_fmt` 刷新（初值=滑条当前值 1）。
2. **音量/亮度返回 → 设置列表（二级菜单）**：新增 `Set_BackToList()`（= `Set_StopTimer` + `Set_Page_Load(Page_Menu)`）；音量/亮度/语言/日期/时间的 返回按钮/ESC 全部改走它；Page0 ESC 仍回主菜单、Page6 仍自动/ESC 回主菜单。
3. **亮度页按返回崩溃（坑 B3-3，重要）**：
   - **现象**：亮度页 ESC/返回 → `Guru Meditation LoadProhibited` @ `lv_event_send`（EXCVADDR=0xC），backtrace 在 `indev_keypad_proc` → `send_event(LV_EVENT_CANCEL)`。
   - **根因**：我此前在 KEY 分支误加 `lv_event_stop_processing(e)`。LVGL9.5 `lv_event_send` 循环 `if(e->stop_processing) break;` 会**先 break 跳过 `e->deleted` 检查**，`res` 保持 OK → `lv_group_send_data` 返回 OK → indev 对已删对象补发 `LV_EVENT_CANCEL` → use-after-free。
   - **正确做法（B2 同款）**：删对象路径**不要** stop_processing，靠 `lv_obj_destructor` 的 `lv_event_mark_deleted` 置 `e->deleted` → 返回 INVALID → indev 提前 return，不补发 CANCEL。
   - **修复**：全部 7 处 ESC/返回删对象分支去掉 `lv_event_stop_processing(e)`（滑条/语言/时间/日期/列表/滚轮/Page6）；纯导航分支（focus 移动，不删对象）保留无害。
4. **语言/日期/时间不存储**：按用户意见**暂不处理**，留待后续"参数存储规划"（阶段 E 音量亮度/充电电量一并做）。

## 各页按键导航（默认 focus + 实测项）

| 页 | 注册对象 | 操作 |
|---|---|---|
| Page0 列表 | 4 list 按钮 | UP/DOWN 切换、ENTER 进入、ESC 返回 |
| Page1/2 滑条 | Slider + 返回按钮 | LEFT/RIGHT 原生调值；**ENTER 前进到返回按钮**、返回按钮上方向键回滑条；ESC 返回 |
| Page3 语言 | 中文/English/下一步 | UP/DOWN 切换、ENTER 进入、ESC 返回 |
| Page4 日期 | 年/月/日滚轮 + 返回/下一步 | 滚轮 UP/DOWN 原生滚动；**ENTER 前进焦点（年→月→日→下一步）**；按钮间 UP/DOWN 切换；ESC 返回 |

> **实测结论（源码确认，烧录验证清单第 6 项）**：LVGL9.5 滑条/滚轮原生处理 `LV_EVENT_KEY`（滑条 4 方向都调值、滚轮 4 方向都滚动），方向键不会切焦点 → 导航统一用 **ENTER 前进焦点** 模式；UP/DOWN 只在普通按钮上做焦点切换。滑条上 LEFT/RIGHT 调值、ENTER 到返回按钮确认、ESC 直返。
