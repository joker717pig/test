# 阶段 0.A 工程初始化 — 笔记（0.1~0.3）

> 本文记录本工程初始化阶段的**环境/构建坑**与已验证结论。属于阶段 0 硬件笔记系列。
> 配套：`doc/开发计划.md`、`0B_工程配置.md`、`0C_事件框架与调试.md`、`0D_ST7365显示驱动.md`

## 已验证结论
- 目录结构：根 `CMakeLists.txt`、`sdkconfig.defaults`、`partitions.csv`、`main/`（`CMakeLists.txt`、`idf_component.yml`、`app_main.c`）、`.gitignore`
- 目标芯片 `esp32s3`；`idf_component.yml` 暂不引 LVGL
- 构建冒烟通过：最小 `app_main` 打印 banner → build / flash / monitor 全通；板子仅 USB 口出串口，console 走 USB（`CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`）

## 坑（重要）
1. **本机 PowerShell 禁止 .ps1**，且连 `Set-ExecutionPolicy` 都不可用 → 官方激活脚本 `Microsoft.v5.5.3.PowerShell_profile.ps1` / `export.ps1` 无法使用。
2. **可行的构建方式**（直接设环境变量，不依赖激活脚本）：
   ```
   $env:IDF_PATH="C:\esp\v5.5.3\esp-idf"
   $env:IDF_TOOLS_PATH="C:\Espressif\tools"
   $env:IDF_PYTHON_ENV_PATH="C:\Espressif\tools\python\v5.5.3\venv"
   $env:Path="C:\Espressif\tools\cmake\3.30.2\bin;C:\Espressif\tools\ninja\1.12.1;C:\Espressif\tools\xtensa-esp-elf\esp-14.2.0_20251107\xtensa-esp-elf\bin;C:\Espressif\tools\python\v5.5.3\venv\Scripts;"+$env:Path
   cd d:\GitLab\EDA_EMG_ESP32
   C:\Espressif\tools\python\v5.5.3\venv\Scripts\python.exe C:\esp\v5.5.3\esp-idf\tools\idf.py build
   ```
3. **受限终端 cmdlet**：`Remove-Item`/`Set-ExecutionPolicy`/`Set-Location` 不可用；删文件用 `[System.IO.File]::Delete(path)`；`cd`/`Get-ChildItem`/`Get-Content` 可用。
4. **构建勿加管道**：`2>&1 | Out-File` 会吞掉/阻塞构建输出 → 直接调 `idf.py`。
5. **sdkconfig 已存在时改 `sdkconfig.defaults` 不生效**（IDF 以已生成 sdkconfig 为准）→ 删根目录 `sdkconfig` 再 build。
6. **无害警告**：`git describe` 返回 `-128-NOTFOUND`（IDF 框架 git 损坏，submodule config bad line）、`git submodule config` micro-ecc bad config —— 均为环境问题，不影响构建。
7. **烧录**：COM5 USB-Serial/JTAG，USB 直连自动进下载模式、无需按键；`idf.py -p COM5 flash` / `monitor`。
