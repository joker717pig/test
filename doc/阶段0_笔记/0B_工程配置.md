# 阶段 0.B 工程配置（N16R8）— 笔记（0.4~0.5）

> 本工程内存/分区配置的坑与验证。属于阶段 0 硬件笔记系列。

## 已验证结论
- Flash 16MB / PSRAM 8MB Octal 80MHz；banner：`Flash 16MB / PSRAM 8MB / Free heap ~8500KB`
- 分区（无 OTA）：`factory`(4MB) + `nvs`(16K) + `phy_init`(4K) + `storage`(~12MB, spiffs)
- `sdkconfig.defaults` 关键项见 `0B` 下方坑 1~3

## 坑（重要，IDF 5.5 符号）
1. `CONFIG_SPIRAM_ALLOW_STACK_EXTERNAL_MEMORY` 在 IDF 5.5 **已改名** `CONFIG_FREERTOS_TASK_CREATE_ALLOW_EXT_MEM`（构建日志会提示 replaced）。
2. `CONFIG_FREERTOS_CHECK_STACKOVERFLOW` 是 **choice**（不能用 `=2`）→ 用 `CONFIG_FREERTOS_CHECK_STACKOVERFLOW_CANARY=y`（Method 2）。
3. `uxTaskGetSystemState` 需要 `CONFIG_FREERTOS_USE_TRACE_FACILITY=y`（注意不是 `ENABLE_TRACE_FACILITY`，那个会被忽略）。
4. Octal PSRAM 必须 `CONFIG_SPIRAM_MODE_OCT=y` + `CONFIG_SPIRAM_SPEED_80M=y`，否则 PSRAM 自检失败。
